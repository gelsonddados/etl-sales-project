# Projeto Profissional de ETL com Airflow + PostgreSQL + Power BI

## Arquitetura do projeto:

Fonte de Dados (CSV/API)<br/>
        ↓<br/>
      ETL<br/>
(Apache Airflow)<br/>
        ↓<br/>
 PostgreSQL (Data Warehouse)<br/>
        ↓<br/>
    Power BI<br/>
(Dashboard Executivo)<br/>

## Stack utilizada:

* Apache Airflow
* PostgreSQL
* Microsoft Power BI
* Docker + Docker Compose
* Python
* Pandas
* SQL
