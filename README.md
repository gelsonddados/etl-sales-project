# Projeto Profissional de ETL com Airflow + PostgreSQL + Power BI

## Arquitetura do projeto:##

Fonte de Dados (CSV/API)
        ↓
      ETL
(Apache Airflow)
        ↓
 PostgreSQL (Data Warehouse)
        ↓
    Power BI
(Dashboard Executivo)

## Stack utilizada:##

* Apache Airflow
* PostgreSQL
* Microsoft Power BI
* Docker + Docker Compose
* Python
* Pandas
* SQL
